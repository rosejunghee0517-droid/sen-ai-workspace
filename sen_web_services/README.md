# 🏫 서울시교육청 교직원 맞춤형 혁신 웹 서비스 설계안 30선
### *"내 친구들과 동료들이 '이걸 네가 혼자 만들었다고?!' 믿지 못할 프로급 웹 서비스"*

> **기술 아키텍처**: 순수 **HTML5 + CSS3 (Tailwind CSS CDN) + Modern JavaScript (ES6+)**
> **배포**: GitHub Pages, Vercel, Netlify 등에 즉시 1초 배포 가능한 완전 정적(Static) 웹 앱
> **AI 엔진**: OpenRouter API (`google/gemini-2.0-flash-exp:free` / `google/gemini-2.5-flash`)
> **데이터**: 인증키 없는 무료 글로벌/공공 API + 혁신적인 프론트엔드 오픈소스 라이브러리

---

## 📌 카테고리 1: 교실 수업 & 학생 맞춤형 에듀테크 (1~6)

### 1. ⚔️ "질문 퐁퐁" 실시간 AI 학급 토론 배틀룸
- **기특한 JS 라이브러리**: `Tailwind CSS`, `Lucide Icons`, `Canvas-confetti`, `RoughNotation` (손글씨 밑줄 강조)
- **무료 No-Key API**: `Wikipedia API` (배경지식 사실 확인)
- **Gemini 역할**: 토론 찬반 입론을 입력받아 즉시 논리적 허점 반박, 중립적 판정 점수 부여, 심사평 자동 생성.
- **깜짝 포인트**: 교실 전자칠판에 띄워두고 학생 둘이 마이크 잡고 발언하면 실시간으로 공방을 시각화하고 폭죽(Confetti) 효과와 함께 승자 판정.

### 2. 🏃‍♂️ 초등·중등 야외수업 & 체육활동 안전 판정관
- **기특한 JS 라이브러리**: `Chart.js` (온습도·자외선 추이), `Animate.css`, `SweetAlert2`
- **무료 No-Key API**: `Open-Meteo Air Quality & Weather API` (초정밀 미세먼지, 자외선, 체감온도, 오존)
- **Gemini 역할**: 교육부 '학교 고농도 미세먼지 및 폭염 대응 매뉴얼' 지침을 기반으로 "오늘 체육관 이동 여부", "단축수업 권고" 판정 및 학부모 알림장 문구 자동 생성.
- **깜짝 포인트**: 학교 위치 버튼 하나만 누르면 기상청보다 깔끔한 직관적 신호등 UI로 교감 선생님과 체육부장님을 단숨에 설득.

### 3. 🧠 3분 스피치 & 생각 그물 마인드맵 즉석 생성기
- **기특한 JS 라이브러리**: `Mermaid.js` (실시간 마인드맵 렌더링), `html2canvas` (이미지 저장), `Typed.js`
- **무료 No-Key API**: `DuckDuckGo Instant Answer API` (키워드 정의)
- **Gemini 역할**: 학생이 두서없이 말한 아이디어나 메모를 분석해 체계적인 대주제-중주제-소주제 마인드맵 다이어그램 코드로 자동 변환.
- **깜짝 포인트**: 텍스트를 몇 자 끄적였을 뿐인데 칠판에 실시간으로 화려한 다이어그램 마인드맵이 인터랙티브하게 펼쳐지고 고화질 PNG로 저장됨.

### 4. ⏳ 인터랙티브 서울 역사 탐험 타임머신
- **기특한 JS 라이브러리**: `Leaflet.js` (서울 지도), `TimelineJS` 또는 모던 수직 타임라인, `AOS` (스크롤 애니메이션)
- **무료 No-Key API**: `Wikipedia REST API` (서울 유적지 및 역사 사건)
- **Gemini 역할**: 특정 연도나 서울 명소(경복궁, 서대문형무소, 몽촌토성 등)를 클릭하면 당시 살았던 가상 인물(조선시대 선비, 독립운동가 등)의 시점으로 역사 일기 생성.
- **깜짝 포인트**: 역사 수업 시간에 아이들이 지도 위의 스팟을 누르면 역사 속 인물과 실시간 인터뷰 대화를 나눌 수 있음.

### 5. 🧾 독서 마라톤 & AI 영수증 감성 서평 발급기
- **기특한 JS 라이브러리**: `jsPDF`, `Html2canvas`, `Barcode.js` (모의 영수증 바코드)
- **무료 No-Key API**: `Open Library API` (책 표지, 저자, 출판 정보)
- **Gemini 역할**: 학생이 읽은 책 이름과 한 줄 감상을 넣으면 '감성 지수 95%', '인생 문장 3개', '생각의 칼로리'를 계산한 감성 영수증 출력.
- **깜짝 포인트**: 인스타 감성의 힙한 영수증 디자인으로 출력되어 학생들이 책 읽고 인증샷 찍어 벽에 붙이는 붐이 일어남.

### 6. 🎡 학급 칭찬 온도계 & 랜덤 미션 룰렛
- **기특한 JS 라이브러리**: `Winwheel.js` (부드러운 회전 룰렛 애니메이션), `Howler.js` (효과음)
- **무료 No-Key API**: `CatFact / Dog CEO API` (힐링 동물 보상 이미지)
- **Gemini 역할**: 오늘의 학급 분위기나 갈등 상황을 입력하면 즉석에서 실천 가능한 '학급 평화 1일 미션' 10가지를 생성해 룰렛에 배치.
- **깜짝 포인트**: 아침 조례 시간 룰렛을 돌리며 교실 분위기가 단번에 밝아지는 학급 경영 필수 앱.

## 📌 카테고리 2: 교육행정 & 교무업무 극한 효율화 (7~12)

### 7. 📄 가정통신문 & 공문서 '쉬운말 3단계' 변환기
- **기특한 JS 라이브러리**: `Diff2Html` (원문과 순화본 변경점 비교), `Clipboard.js`
- **무료 No-Key API**: 국립국어원 공공 데이터 연계 프롬프트
- **Gemini 역할**: 딱딱한 교육청 공문서 원문을 [1단계: 학부모용 다정한 안내문], [2단계: 다문화 가정을 위한 쉬운 한국어], [3단계: 10초 요약 문자(SMS)]로 동시 변환.
- **깜짝 포인트**: 행정실/교무실에서 30분 걸려 쓰던 가정통신문을 복붙 3초 만에 완벽한 톤으로 변환해 동료 교사들이 경악함.

### 8. 🚌 현장체험학습 & 수학여행 안전 계획서 원클릭 생성기
- **기특한 JS 라이브러리**: `SortableJS` (일정 드래그앤드롭 재배치), `jsPDF` (계획서 다운로드)
- **무료 No-Key API**: `Open-Meteo` (출발지/도착지 날씨) + `OpenStreetMap Nominatim` (병원/소방서 거리)
- **Gemini 역할**: 방문지, 학생 수, 이동 수단을 입력하면 이동 경로상 안전 점검 체크리스트, 비상 연락망 서식, 우천 시 대체 프로그램을 완벽한 양식으로 작성.
- **깜짝 포인트**: 교사들이 가장 꺼리는 현장체험학습 안전 계획서 결재 문안을 1분 만에 완성.

### 9. 🧩 동아리/방과후학교 드래그앤드롭 스마트 스케줄러
- **기특한 JS 라이브러리**: `FullCalendar.js`, `SortableJS`
- **무료 No-Key API**: `WorldTimeAPI` (표준 시간 동기화)
- **Gemini 역할**: 강사 일정, 특별실(컴퓨터실, 과학실, 강당) 중복 충돌을 감지하고 최적의 스케줄 재배치 제안.
- **깜짝 포인트**: 복잡한 교실/강사 배치를 마우스로 척척 옮기면 AI가 "3교시 과학실 중복 충돌 발생! 대안: 4교시로 변경 권장"을 즉각 경고.

### 10. 🎤 교원 연수 & 학부모 총회 즉석 아이스브레이킹 대시보드
- **기특한 JS 라이브러리**: `WordCloud2.js` (워드클라우드 실시간 시각화), `Canvas-confetti`
- **무료 No-Key API**: `Open Trivia DB` (넌센스/상식 퀴즈)
- **Gemini 역할**: 연수 주제(예: 'AI 디지털 교과서', '고교학점제')에 맞춘 교직원 공감 밸런스 게임 질문 및 어색함을 깨는 오프닝 멘트 생성.
- **깜짝 포인트**: 대형 스크린에 띄워놓고 교원들이 스마트폰으로 참여하면 즉시 워드클라우드가 춤추며 연수 분위기를 압도.

### 11. ✍️ 학생 관찰일지 & 생활기록부 행동특성 문장 빌더
- **기특한 JS 라이브러리**: `Tagify` (역량 태그 선택 인터페이스), `Marked.js`
- **무료 No-Key API**: 교육부 기재요령 가이드라인 프롬프트
- **Gemini 역할**: 학생의 핵심 키워드(예: '책임감 높음', '발표 수줍으나 보고서 우수')를 넣으면 교육부 금지어(교외 수상, 부모 직업 등)를 자동 필터링하고 생기부 표준 문체로 변환.
- **깜짝 포인트**: 연말 생기부 지옥 기간에 동료 교사들이 이 사이트 링크 달라고 줄 서게 됨.

### 12. 📰 교육청 공문서 요약 10초 모바일 카드뉴스 생성기
- **기특한 JS 라이브러리**: `Swiper.js` (카드 슬라이드 터치 뷰), `html2canvas` (카드별 이미지 다운로드)
- **무료 No-Key API**: 없음 (순수 문서 파싱)
- **Gemini 역할**: 긴 공문서 텍스트를 카드뉴스 4~5장 규격(핵심 요약, 대상자, 신청 기한, 문의처)의 제목/본문 구조로 쪼개어 자동 배치.
- **깜짝 포인트**: 교직원 메신저나 학교 밴드에 올리기 딱 좋은 세련된 카드뉴스가 10초 만에 제작됨.

## 📌 카테고리 3: 학생 상담, 생활지도 & 마음건강 (13~18)

### 13. 📮 마음 우체통: 학생 감정 일기 & AI 온기 답장소
- **기특한 JS 라이브러리**: `Tone.js` (부드러운 피아노 배경음 생성), `Paper.js` (종이 텍스처 질감)
- **무료 No-Key API**: `Advice Slip API` (위로와 지혜의 명언)
- **Gemini 역할**: 학생이 털어놓은 속마음(학업 스트레스, 친구 관계)을 비판 없이 무한 공감해주고, 위로의 편지와 오늘 들으면 좋은 음악 스타일 처방.
- **깜짝 포인트**: 학생들이 비밀스럽게 접속해 속마음을 털어놓고 눈물 흘리며 위로받는 힐링 웹 앱.

### 14. 🤝 학급 평화 지킴이: 갈등 중재 3자 시뮬레이터
- **기특한 JS 라이브러리**: `ChatBubble UI`, `Lottie-web` (캐릭터 애니메이션)
- **무료 No-Key API**: 없음
- **Gemini 역할**: 두 학생 간의 다툼 상황(A학생 입장, B학생 입장)을 입력받아 '비폭력 대화(NVC)' 원칙에 입각한 서로의 숨은 감정 해석 및 화해를 위한 사과 문장 제안.
- **깜짝 포인트**: 생활지도부장 선생님이 보고 "이거 당장 학폭 화해 조정 상담에 쓰자"고 감탄할 솔루션.

### 15. 🧭 서울 꿈 찾기: 인터랙티브 진로 탐색 월드맵
- **기특한 JS 라이브러리**: `D3.js` 또는 `Vis.js` (인터랙티브 진로 연결 네트워크 그래프)
- **무료 No-Key API**: `Hipolabs Universities API` (전국 학과 및 대학 정보)
- **Gemini 역할**: 학생의 취미, 좋아하는 과목 3가지를 선택하면 전통적인 직업뿐 아니라 미래 유망 직업군 5가지와 추천 고교·대학 진로 로드맵 제시.
- **깜짝 포인트**: 마인드맵 노드를 클릭할 때마다 미래 진로 가지가 유기적으로 뻗어나가는 비주얼 쇼크.

### 16. 🎧 수험생 집중 충전소 & 뽀모도로 ASMR 방
- **기특한 JS 라이브러리**: `Howler.js` (빗소리, 모닥불, 도서관 사운드 믹서), `Progressbar.js`
- **무료 No-Key API**: `wttr.in / Open-Meteo` (현재 바깥 날씨와 실시간 배경 사운드 자동 동기화)
- **Gemini 역할**: 공부할 과목과 목표 시간을 입력하면 25분 집중 + 5분 휴식 타이머에 맞춰 맞춤형 응원 멘트 및 뇌 피로도 회복 퀴즈 출제.
- **깜짝 포인트**: 실제 비가 오면 자동으로 빗소리 ASMR이 믹싱되며 집중 모드로 전환되는 감성 인터페이스.

### 17. 🎭 학교폭력 예방 인터랙티브 롤플레잉 드라마
- **기특한 JS 라이브러리**: `Typed.js`, `Howler.js`, 선택지 기반 분기형 비주얼 노벨 UI
- **무료 No-Key API**: 없음
- **Gemini 역할**: 학생의 선택(방관하기, 말리기, 선생님께 알리기 등)에 따라 실시간으로 스토리 분기를 생성하여 그 행동이 가져올 결과를 체험하게 함.
- **깜짝 포인트**: 뻔한 주입식 예방 교육이 아니라 게임처럼 몰입감 넘치는 인터랙티브 스토리텔링.

### 18. 💬 학부모 상담 사전 공감 화법 코치
- **기특한 JS 라이브러리**: `Driver.js` (스텝 바이 스텝 가이드 투어), `Prism.js`
- **무료 No-Key API**: 없음
- **Gemini 역할**: 까다로운 학부모 상담 질문 시나리오(성적 불만, 교우 관계 이의제기 등)를 제시하고, 교사가 답변을 입력하면 '경청·공감·협력적 해결' 관점에서 코칭 피드백 제공.
- **깜짝 포인트**: 신규 교사들의 상담 울렁증을 단번에 없애주는 비밀 과외 선생님.

## 📌 카테고리 4: 서울 로컬 교육 & 생태·체험학습 인프라 (19~24)

### 19. 🗺️ 서울 25개 자치구 교육·체험학습 탐방 지도
